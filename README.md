# WORLD ORDER v1.0.0

국가를 선택하고 경제, 정치, 사회, 기술, 외교, 군사를 관리하며 세계 역사를 만들어가는 한국어 웹 대전략 시뮬레이션 게임입니다.

## 주요 기능

- 세계 지도와 국가 선택
- 월간 경제·정치·사회·기술·외교·군사 시뮬레이션
- 산업·기업·가계·금융·공급망 경제
- 연구기관·기술혁신·상용화·특허
- 국가별 AI 성향·장기 목표·적응형 의사결정
- 동적 사건·뉴스·국가 역사·세계 역사
- 국가 상황 요약·위험/기회 분석
- 3개 세이브 슬롯·자동 저장·백업·버전 마이그레이션

## 플레이 방법

1. 새 게임에서 국가를 선택합니다.
2. `다음 턴`으로 한 달을 진행합니다.
3. 국가 상황 요약에서 위험과 기회를 확인합니다.
4. 연구·경제·외교·군사 패널에서 행동을 선택합니다.
5. 저장 메뉴에서 수동 저장하거나 자동 저장을 사용합니다.

## 실행 및 빌드

```bash
npm install
npm run dev
npm run build
```

## 기술 스택

- React
- TypeScript
- Vite
- Zustand
- SVG 기반 지도

## 프로젝트 구조

- `src/components`: 게임 화면과 패널
- `src/game`: 경제·정치·기술·군사·외교·AI·이벤트 시뮬레이션
- `src/store`: Zustand 게임 상태와 월간 Tick
- `src/data`: 국가와 시스템 데이터
- `src/types`: 공유 게임 데이터 구조

게임은 클라이언트에서 동작하며 저장 데이터는 브라우저 저장소에 보관됩니다.
