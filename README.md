# 증기와 장부

가상의 아르델 공업지대에서 AI 회사 두 곳과 경쟁하는 1인용 웹 산업 네트워크 보드게임입니다.

## 실행

```powershell
python -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 핵심 흐름

1. 손의 도시·산업 카드 한 장을 선택합니다.
2. 산업 건설, 운송로, 판매, 개발, 대출, 정찰 중 행동합니다.
3. 공동 연료·기계·화물을 이용하고 산업을 뒤집습니다.
4. 라운드에 적게 지출한 회사부터 다음 라운드에 행동합니다.
5. 수로기 5라운드와 철도기 5라운드 끝에 산업·운송로를 결산합니다.

첫 화면의 `규칙서 보기`에서 실제 구현과 일치하는 8쪽 규칙서를 읽을 수 있고, 게임 중에도 왼쪽 장부에서 다시 열 수 있습니다.
